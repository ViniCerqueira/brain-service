                 Wallisson dos Santos Gomes Commented 3 months ago
                 @Lily Li -- answers to all six sub-questions plus the follow-up:
                 Q1. Daily base = prior month ÷ 30. Always, regardless of monthly/daily group/part-time?

                 No -- only for monthly-group employees. For monthly-group workers: prior month's BCCC
                 ÷ 30. For daily-group workers: prior month's BCCC ÷ actual calendar days of that month
                 (28/30/31). Part-time has a different BR calculation entirely (sum of last 3 months ÷
                 calendar days in the period, per RDL 11/2024). So ÷30 is not universal -- it depends on the
                 cotización group.
                 Q2. Leave days = 30 - days worked. What if multiple leave types in the same month?

                 The formula stays the same for the base calculation: total days in period - worked days =
                 leave days (for monthly group, period = 30). But when there are multiple leave types, the
                 contribution base for each leave segment is calculated separately using the BR of that
                 leave type (BCCC for common-contingency leave, BCCP for professional-contingency
                 leave, BCCC M-2 for birth/care). You segment the month: worked days use current-month
                 actual earnings; each leave block uses its own prior-month base. The total BCCC/BCCP for
                 the month is then the sum of all segments (see follow-up below).
                 Q3. For worked days, apply current month's actual BCCC/BCCP base?

                 Yes -- worked-day segment base = actual earnings for those days in the current month,
                 subject to normal floor/ceiling.
                 Q4. If maternity/sick leave covers all 30 days -- only BCCC, no BCCP?

                 Yes. If the entire month is common-contingency leave (sick leave, maternity, disabling
                 menstruation, etc.), the contribution base for the month is 100% BCCC-sourced (prior
                 month's BCCC ÷ 30 × 30 days = prior month's BCCC). No BCCP base applies because
                 there are zero professional-contingency days.
                 Q5. If entire month is work accident leave -- only BCCP, no BCCC?

                 Yes. Professional-contingency leave uses prior month's BCCP as the daily base. If all 30
                 days are AT/EP, the month's contribution base is 100% BCCP-sourced. No BCCC base for
                 those days.

So during a common sick leave, AT/EP (BCCP) still runs on the prior-month BCCP; during
an AT leave, common (BCCC) still runs on the prior-month BCCC. Neither base is ever zero
while the worker is de alta.

So Q4 ("all-month sick  only BCCC, no BCCP") and Q5 ("all-month AT  only BCCP, no
BCCC") are both No -- both bases are maintained at the prior-month level. Contingency
type drives the payout and which prior-month base is referenced, not whether a base
exists.
Further Query 3 -- worked-day base, and floor/ceiling
Worked-day base is not in BCCC only. Worked-day earnings are the cotización base for
both common and professional contingencies, so they feed both:

| Monthly BCCC | worked-day earnings + all leave days × (prior-month BCCC ÷ 30) |

| Monthly BCCP | worked-day earnings + all leave days × (prior-month BCCP ÷ 30) |
Floor/ceiling applies to the monthly BCCC and the monthly BCCP (both), not to the
worked-day base only:

For a worker de alta the entire month (working part, on leave part), the full monthly base

mínima (by group) and tope máximo (5,101.20/month, 2026) apply. They are not scaled

down by worked days. Proration by days is the alta/baja rule (worker in alta only part of

the month) -- it does not apply to the worked-vs-leave split inside a full month of alta.
