                            $hr.number_of_additional_hours_contract_part_time (H02)
                            $hr.number_of_hours_of_face_to_face_theoretical_training (H03)
                            $hr.number_of_hours_of_distance_theoretical_training (H04)
                            $hr.coefficient_part_time_in_situation_of_ere (H05)
                            $hr.number_of_tutoring_hours_training_contracts (H06)
                            $legal_entity_hr.software_vendor_code_registered_with_tgss — ETI header
                           field 50, "Identificador de sintaxis de proceso" (an..4, pos. 9, pattern W0xx)
                            $legal_entity_hr.process_syntax_version_number — ETI header field 60,
                           "Número de versión de sintaxis de proceso" (n1, pos. 13)

                      Source for the last two: seg-social.es "Sistema RED – Mensaje de Afiliación (AFI)," Ed.
                      05/2025 — the ETI header is shared across AFI/CRA/Bases.

                   3. Base code 537 → 58151 (BCCC), not 58153. Horas complementarias are regular
                      working hours under Art. 12.5 ET, same contingency group as code 500 — no
                      professional-risk nature. Wage type not yet built in the WTC; mapping logic
                      documented, amount pending product build.

                   4. Indicator codes confirmed:

                           51 = Modalidad Salario (M, only for daily contribution groups 08–11)

                           52 = Opción Epígrafe 126 (only applies when period = 2006 — dead code for any
                           current submission)

                           54 = Motivo de presentación de L03 (mandatory whenever Settlement Type = L03,
                           5 values)

                       $legal_entity_hr.reason_for_l03_submission created in the DD, backed by a new
                      5-value option mapper matching 54 (1 Atrasos de convenio, 2 Normativa/disposición
                      legal, 3 Acto de conciliación, 4 Sentencia judicial, 5 Cualquier otro título legítimo).

                   5. Settlement Type does not depend on a single selection of
                       $legal_entity_hr.tgss_bases_settlement_type , and the user is not limited to one
                      type per generation. A BASES file can carry multiple types — your L00+L13 sample
                      confirms this. Trigger: each type fires per block/tramo, based on that block's own
                      circumstance (e.g. regular month → L00; termination + untaken vacation → L13), not a
                      single file-level choice. Every type's specific trigger condition is documented in the
                      Settlement Type Codes table (Field Options sheet) — L13's is detailed in point 6
                      below.

                   6. L13 is exclusive to terminated workers' untaken-vacation payout — not a same-
                      period top-up. Calculated on a daily base for the vacation-equivalent period, using
                      whichever base codes normally applied to that worker (500 for CC, 601/603 for AT/EP
                      where applicable) — not restricted to 500. Submitted as its own block alongside the
                      termination month's block, same settlement month.
