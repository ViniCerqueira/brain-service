Hi team,
With the new change to Instaroll, some steps that were previously done manually when
calculating the vacation bonus now need to be automated.
When the vacation bonus exceeds 95 UVT, social security and withholding taxes must be
deducted from the bonus amount. Since the system doesn’t do this, we used to calculate it
ourselves and, in step 3, adjust the bonus amount if necessary.
Currently, vacation days are recorded under account code 63123, and the account code used to
calculate the bonus amount is 62837, which is the one that appears in G2N.
Could you please help us with that?

                  Two scope rules that constrain the automation:

                       Salario Integral is always excluded from this offcycle. Only Personnel Area CO =
                       Ordinario .
                       The retention procedure is already in the system — option 6 of the employee card. For
                       Procedure 2 employees the fixed percentage is stored on WT 52552. The automation
                       should read both from there rather than expecting an input file.

                  2. Input values

                  Field                                       Value
                  ------------------------------------------  --------------
                  Total Días (input loaded on WT 63123)       13
                  Gross bonus under 62837, before adjustment  12,940,200 COP

                                                                                                              Plain text

                  Total Días = Days Taken + Cash Out Amount — both components must be summed.
                  Using Days Taken alone is a known error source in the manual process.

                  Bonus formula (this is what HRBlizz already produces today, and it is correct):

                     Gross bonus = ROUND( Total Días × 2.8 × (Monthly base salary / 30), 0 )
                                         = ROUND( 13 × 2.8 × (10,665,000 / 30), 0 )
                                         = 12,940,200
