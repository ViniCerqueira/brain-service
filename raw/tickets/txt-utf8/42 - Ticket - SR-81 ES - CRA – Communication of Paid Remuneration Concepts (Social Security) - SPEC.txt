Wallisson dos Santos Gomes  Commented 5 months ago
@Lily Li

Your reading of Settlement Month/Year is correct — CRA reports remuneration in the
period it was actually paid.
For 58197/58198 specifically: the severance payment itself is made in the termination
month. It is not a retroactive payment — it did not occur in prior months. The BASES L03
proration is a contribution base attribution mechanism that tells TGSS to spread the SS
base across prior months, but the actual payment event happened once, in the
termination month.
Therefore:

CRA: report 58197 (0054/I) and 58198 (0054/E) in the termination month only — one
record each for the full amounts. No proration in CRA.
BASES: use L03 to distribute base code 701 across the prior 12 months.

                 terminated employee (ESP04, Spain Reports Testing, Feb 2026) the payroll posted 62100
                 Basic salary = 4,000.00 (prorated) and 79450 Vacation cashout leave payout = 2,000.00.
                 Both wage types are mapped to CRA code 0001 in the spec sheet "Pay Elements with CRA
                 Code", so they are summed into one CRE 0001 record of 6,000.00. The match with the
                 salary card value is a coincidence.
